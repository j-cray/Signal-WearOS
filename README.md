# Signal-WearOS

A standalone Signal messenger client for WearOS smartwatches.

## Status
**Maintenance Mode** - Basic functionality works, but active development has slowed.

## Features
- [x] Link device via QR code (as a secondary device).
- [x] View conversation list.
- [x] Send text messages.
- [x] View recent message history.
- [ ] View attachments (Images/Audio).
- [ ] Voice notes support.
- [ ] Reply via voice input.
